# NGX Multi-Factor Research Platform

This repository is the starting monorepo for the academic research platform described in `README.md`.

The current scaffold includes:

- a responsive Next.js research console with seeded, clearly-labelled demo observations;
- typed frontend API seams ready to switch from demo data to FastAPI;
- a FastAPI backend with the documented route surface and quantitative module boundaries;
- a Python factor/quant layer where deterministic calculations can be implemented and tested;
- data, database, graph, scripts, docs, and CI directories matching the research architecture.

Demo outputs are not claims about the Nigerian Exchange. They exist only to make the application navigable before a research dataset is loaded.
